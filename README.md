# KeepTyping

Keep typing in WoW chat while clicking in the world or turning the camera. Originally released as ChatFix 8.3, this update was tested on World of Warcraft Retail 12.1.5 (interface 120105).

[Download KeepTyping for Retail 12.1.5](https://github.com/VraulJawrip/ChatFix-8.3/raw/refs/heads/main/KeepTyping-12.1.5.zip)

## Installation

1. Exit WoW. If upgrading, remove the old `ChatFix 8.3` folder from `Interface/AddOns`.
2. Extract the ZIP into `_retail_/Interface/AddOns`. The resulting path should be `KeepTyping/KeepTyping.toc` inside `AddOns`.
3. Launch WoW and enable **KeepTyping** in the AddOns list.
